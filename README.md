# 哆啦A夢風格活動報告 - AI智慧圖說生成器

這是一套基於資料夾內 `Ai圖說程式碼.docx` 建立並全面升級的**單頁式活動報告與 AI 圖說製作網頁**。

---

## 🌟 核心特色與功能

### 1. 經典主題與版面設計
- **哆啦A夢主題風格**：包含經典鈴鐺、百寶袋幸運草、銅鑼燒、星星裝飾背景與彩虹標題底線。
- **標準 A4 滿版排版**：精準模擬 $210\text{mm} \times 297\text{mm}$ A4 直式規格，所見即所得。
- **5 種主題色彩**：哆啦A夢藍、哆啦美粉紅、大雄森林綠、靜香陽光橘、小叮鈴亮黃。
- **4 種鈴鐺配色**：經典金、未來銀、熱情紅、科技藍。
- **靈活格位配置**：支援 1 格（滿版）、2 格（上下）、3 格（上1下2）、4 格（田字）、6 格（經典六格）。

### 2. Google Gemini AI 智慧看圖說故事
- **一鍵自動生成**：上傳照片後，AI 會依據照片細節自動產出 18 字以內的繁體中文溫馨圖說。
- **設定工具箱（右上角 ⚙️）**：
  - 可直接填入您的 **Google Gemini API Key**（支援儲存於瀏覽器 LocalStorage，下次開啟免重填）。
  - 提供快速取得 API Key 的連結與「⚡ 測試連線」功能。
  - 支援模型切換：`gemini-2.5-flash`（最新推薦）、`gemini-2.0-flash`、`gemini-1.5-flash`。
  - 支援風格語氣切換：「溫馨童趣」、「活力熱情」、「探究觀察」或自訂提示詞。
  - 單張重新生成（🔄）與「全部重新分析」按鈕。

### 3. 便捷的照片管理體驗
- **拖曳上傳（Drag & Drop）**：可直接將電腦中的照片拖入對應格位。
- **批次選圖**：點擊「📷 批次選圖」一次選取多張照片自動依序排入。
- **懸停操作**：滑鼠懸停於照片上可快速「🔄 更換」或「🗑️ 刪除」。
- **載入示範**：點擊「✨ 載入示範」可一鍵填入美觀的活動範例圖文，方便快速預覽效果。

### 4. 多元匯出與無損列印
- 📄 **下載 PDF**：以高解析度 Canvas 封裝為標準 A4 PDF。
- 📝 **下載 Word**：匯出符合 MSO Word 規範的 A4 滿版 `.doc` 檔。
- 🖼️ **下載圖片**：匯出高解析度 PNG 圖片，方便直接於通訊軟體（LINE、FB、ClassDojo）發送。
- 🖨️ **直接列印**：支援 `@media print` 向量級直出，自動隱藏所有控制項與無關按鈕。

---

## 🚀 使用方式

1. **開啟網頁**：直接以任一現代瀏覽器（如 Microsoft Edge、Google Chrome）開啟 [`index.html`](file:///d:/0網頁/Ai圖說/index.html)。
2. **輸入標題與日期**：直接點擊頁面頂部的標題與日期文字進行修改。
3. **上傳照片**：點擊任一格位或拖入照片，即可自動/手動輸入說明文字。
4. **設定 AI Key（選用）**：點擊右上角 ⚙️ 工具箱輸入您的 Gemini API Key 享受全自動 AI 圖說。
5. **匯出報告**：點擊畫面底部的浮動匯出按鈕，選擇下載 PDF、Word、圖片或直接列印。
